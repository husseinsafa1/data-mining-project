# **Diabetic Retinopathy detection CNN**

# 

##### *Description:*



This project implements a Convolutional Neural Network (CNN) for the binary classification of diabetic retinopathy from retinal fundus images. The model is developed using TensorFlow and Keras and is designed as a screening tool for educational and data mining purposes.



##### *Installation:*

 

pip install tensorflow numpy scikit-learn pillow matplotlib streamlit



##### *Usage:*



-Train the CNN model using the provided training script.

-Save the trained model (.keras format).

-Launch the Streamlit app.

-Upload retinal image to get predictions.



##### *Structure:*



A general folder containing the data folder with the notebook of training the model (.ipynb) and the "app.py".

The data folder should contain three separate folders:

* training (2 folders for DR and No\_DR) 
* validation (folders for DR and No\_DR)
* testing (2 folders for DR and No\_DR)





Note: this project is made for us to understand image classification as part of our data mining project, it is only for educational reasons it is not clinically approved nor licensed. It is a beginner friendly model created by students.
